# ⭐ Product Sentiment Analyzer & Review Dashboard

A Python-based application that analyzes product reviews and identifies customer sentiment.

## ✨ Features
- Analyzes customer product reviews.
- Classifies positive and negative sentiments.
- Processes review text using NLP techniques.
- Displays sentiment analysis results.
- Provides a review dashboard.

## 🛠️ Technologies Used
Python | Machine Learning | NLP | Flask | HTML | CSS

## ⚙️ How to Run

```bash
pip install flask pandas scikit-learn
python app.py
```
